Research

Final-year project · 2026 – present

A Lightweight Model-Behavior-Aware Update Validation and Rollback Framework for Resource-Constrained Edge AI Devices

P. H. A. Dilmani, supervised by D. Rajasinghe

Over-the-air updates on phones and cars check that an update installs and boots correctly. They do not check whether a new AI model still behaves correctly. A model can install perfectly and still lose accuracy or slow down.

This framework tests a candidate model on the device before committing it. It compares accuracy, confidence and latency against the running model on a small held-out validation set, and rolls back automatically if the new model regresses. The evaluation injects network loss, power loss and deliberately degraded models, and compares validation strategies against an install-only baseline.

My role: individual project. I am designing and building the framework and running the evaluation.

Off-Grid LoRa-Based Emergency Messaging System for Disaster-Prone Communities in Sri Lanka

P. H. A. Dilmani, J. A. S. V. Jayasundara, S. K. Upawansa, D. Rajasinghe

An emergency messaging system that keeps communities connected when mobile networks and the internet fail, using long-range, low-power LoRa radio links. Messages travel over LoRa to a Raspberry Pi gateway and are then forwarded to a server for coordination.

My role: built the WebSocket gateway that forwards LoRa messages from the Raspberry Pi to the central server in real time (serial data handling, hardware–software integration), and co-wrote the paper. The project was among the highest-marked in our cohort.

Challenges of Integrating AI into Safety-Critical Automotive Software: A Review

P. H. A. Dilmani

A literature review of what makes machine-learning components hard to certify in vehicles, and how current standards respond, covering ISO 26262 (functional safety), ISO 21448 / SOTIF (safety of the intended functionality) and ISO/PAS 8800 (AI in road vehicles).
